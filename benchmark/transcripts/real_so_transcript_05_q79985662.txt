Title: TreeDataGrid with XAML-defined columns can't resolve view model properties
================================================================================

The code is pretty much the response to a Copilot prompt:

 

For Avalonia 12 using MVVM Community Toolkit, write a program that implements a `TreeDataGrid`. There is an enum called `ShapeType` with members `Circle`, `Square`, and `Triangle`. There is a class called `ShapeOption` that includes a property named `OptText` of type string and a property named `OptShape` of type `ShapeType`. There is a view model class named `ShDrawnVM` that includes the boolean properties `IsFilled` and `IsRoundedCorners`, plus a `ShapeType` property named `Shape`. There is a view model class named `ShapesDrawnVM` that includes a property named `DrawingShapes` of type `ObservableCollection ` and a property named `ShapeOptions` of type `ObservableCollection `. There is a `ShapesDrawn` window that has a `ShapesDrawnVM` as its `DataContext` and `ShapesDrawnVM.DrawingShapes` is the `ItemsSource` of the `TreeDataGrid`. Each row in the `TreeDataGrid` has a checkbox each for `ShDrawnVM.IsFilled` and `ShDrawnVM.IsRoundedCorners` and a combobox for selection of `ShDrawnVM.Shape`. The `ShapesDrawnVM.ShapeOptions` is the `ItemsSource` for the combobox, which displays the `ShapeOption.OptText` and has `ShapeOption.OptShape` bound to `SelectedValue`.

 

This produced an example that had `ShapesDrawnVM` create a `FlatTreeDataGridSource` and had one line of XAML for the `TreeDataGrid` after a `Resources` tag that defined a single `DataTemplate` that mentioned only `ShDrawnVM.Shape`, not its other `bool` properties. I prefer that the columns be defined in XAML so I did not implement it, instead immediately following up with:

 

How to define the TreeDataGrid columns in XAML?

 

I also added these lines in the `Window` tag:


```
 xmlns:vm="clr-namespace:MyProject.ViewModels;assembly=MyProject"
 xmlns:views="clr-namespace:MyProject.Views"
 x:Class="MyProject.Views.ShapesDrawn"
 x:DataType="vm:ShapesDrawnVM"

```


Implementing and attempting to build this produces the following errors:

 

Unable to resolve property or method of name 'ShapeOptions' on type 'System.Object'. (points to ComboBox ItemsSource) 

 
 

Unable to resolve property or method of name 'Shape' on type 'XamlX.TypeSystem.XamlPseudoType'. (points to ComboBox SelectedValue) 

 
 

Unable to resolve property or method of name 'IsRoundedCorners' on type 'MyProject.ViewModels.ShapesDrawnVM'. (points to TreeDataGridCheckBoxColumn) 

 

I tried adding `x:DataType="vm:ShDrawnVM"` to each column's `TreeDataGridCheckBoxColumn` or `DataTemplate` tag, but this still left the `ShapeOptions` error.


Any help appreciated, thanks.
